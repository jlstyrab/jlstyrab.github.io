# jlstyrab.github.io

Projektsidor som QR-koderna pa enheternas etiketter pekar pa —
`https://jlstyrab.github.io/<projekt>`. Poangen: adressen kan aldrig ge 404
aven om projektrepot ar privat, och den ar gratis-hostad av GitHub Pages
(ingen server att betala).

## Nytt projekt

Kopiera `optaRokgasflakt/index.html` till `<projektnamn>/index.html`,
uppdatera texten, lagg till en rad i rot-`index.html`.

## Nar ett projektrepo gors publikt

Aktivera den bortkommenterade `<meta http-equiv="refresh">`-raden i projektets
`index.html` — da hoppar sidan direkt vidare till repot och etiketten behover
aldrig tryckas om.
