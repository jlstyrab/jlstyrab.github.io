optaRokgasflakt K0

Styrning av rökgasfläktar i tre trapphus. Fristående Arduino Opta utan nätverksanslutning — startslinga med kodmotstånd, linjeövervakning och inbyggd händelselogg.

Kontrollera status på plats

  • Lysdioden uppe till vänster blinkar kort varje sekund — programmet lever.
  • D0, D1, D2 lyser när fläkten i trapphus A, B respektive C är startad. D3 lyser fast när allt är friskt.
  • Röd lysdiod blinkar vid fel på startslingan: långsamt = avbrott, snabbt = kortslutning. Fläktarna behåller då sitt senaste läge.
  • Logg: anslut en dator till USB-C och öppna en seriemonitor på 115200 baud. Status skrivs varje sekund. Vid start skrivs svarta lådans rapport: antal omstarter, hur många som var oväntade och vad enheten gjorde innan senaste omstart.
  • Utgångstest: håll USER-knappen intryckt i 2 sekunder. Korta tryck stegar sedan D0 → D1 → D2 → D3 → alla av. Håll 2 sekunder igen för att avsluta (annars avslutas testet efter 10 minuter). Obs: testet startar fläktarna på riktigt.
